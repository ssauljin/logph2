# Manuscript draft

`main.tex` – "Second-order behaviour of log phase-type tails and threshold-robust tail index estimation".
Formatted for submission to the *Scandinavian Actuarial Journal* (Taylor & Francis), following the
T&F manuscript layout guide: Times 12 pt, double spacing, line numbers, 2.5 cm margins, abstract of about
200 words, author-date references, and disclosure / funding / data availability statements before the
references. Taylor & Francis no longer offers a LaTeX class for this journal, and the journal's own
instructions page could not be checked from the build environment, so verify the items listed in the
pull request against the journal's Instructions for Authors before submitting.
`main.pdf` – compiled draft. Red bracketed text marks items for the authors (second author's email, code URL,
acknowledgements, draft date).

* `tables/` – generated by `python3 make_tables.py` from the simulation outputs in `../sim`
  (`summary_table.csv`, `n10000/`, `results_tables.txt`, `coverage_n2000.txt`); do not edit by hand.
* `figures/` – copies of the simulation figures in `../sim` and `../sim/n10000`.
* `empirical.py` – threshold plot of Hill / GPD / Exp+Erlang PH2 estimates with profile-likelihood
  bands, for the empirical section: `python3 empirical.py losses.csv [column] [outprefix] [--shift]`.
  Section 7 uses the Danish fire losses (n = 2167, 1980-1990; e.g. `danish` in the R package
  `evir`). The raw data file is not committed; `figures/danish.csv` holds the per-threshold estimates.
  Reproduce with `python3 empirical.py danish.csv Loss figures/danish && python3 make_tables.py`.
* `empirical_risk.py` – expected shortfall and excess-of-loss layer premiums by threshold and
  method, with 95% profile-likelihood intervals (Section 8.1):
  `python3 empirical_risk.py danish.csv Loss 11` (11 = years of data, for the claim frequency).
* `../sim/riskmeasures.py` – closed-form stop-loss transforms, ES and layer premiums for the
  Exp+Erlang, GPD and Pareto tails; profile-likelihood intervals for any of them
  (`check` verifies the closed forms; `coverage` runs the interval coverage study).
* `../sim/fisher_B.py` – closed-form Fisher information for the Exp+Erlang sub-model
  (`check`, `table`, `coverage` sub-commands).

Build:

```bash
python3 make_tables.py
pdflatex main && bibtex main && pdflatex main && pdflatex main
```
